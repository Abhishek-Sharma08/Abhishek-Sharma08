# 🚀 Featured Projects

### 🚀 [CollabOS](https://github.com/Abhishek-Sharma08/CollabOS)
AI-powered collaboration platform for software teams.

**Stack:** Fastify • PostgreSQL • Prisma • Redis • BullMQ • Socket.IO

**Key Features**
- JWT authentication & RBAC
- Redis-backed refresh tokens
- BullMQ background jobs
- GitHub OAuth & webhooks
- Real-time collaboration via Socket.IO

### 🤖 [AI Gateway](https://github.com/Abhishek-Sharma08/ai-gateway)
Production-style gateway for routing requests across multiple AI providers.

**Stack:** Fastify • Redis • Docker

**Key Features**
- Streaming AI responses
- Provider abstraction layer
- Automatic retry & failover
- Response caching
- Rate limiting

### ❄️ [SnowVault](https://github.com/Abhishek-Sharma08/SnowVault)
Gamified coding platform built during an AWS hackathon.

**Key Features**
- Interactive, progress-tracked learning
- Lesson management system
- Scalable backend for coding challenges

### ⚡ [Redis CacheHub](https://github.com/Abhishek-Sharma08/redis-cachehub)
Backend service demonstrating production Redis caching patterns.

**Stack:** Express • ioredis • MongoDB • Docker

**Key Features**
- Cache-aside pattern with TTL strategies
- Cache invalidation & keyspace notifications
- Benchmarking cached vs. uncached performance
